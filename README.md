# Горничная 2.0

Личный помощник: Telegram-бот и приложение для ПК (Electron) с виджетом поверх всех окон.
Пишете как есть — горничная сама раскладывает по дневнику, планам, задачам, важным датам,
привычкам, деньгам, показателям и памяти. Устройство и решения — `docs/АРХИТЕКТУРА.md`.

## Запуск сервера

```
npm install
copy .env.example .env      (заполнить, см. ниже)
npm run server
```

Нужен Node 22+. Сервер запускается и без ключей — выключено то, для чего ключа нет.

| В `.env` | Зачем |
|---|---|
| `TELEGRAM_BOT_TOKEN` | бот (новый, от @BotFather; старого бота не трогаем) |
| `ALLOWED_CHAT_IDS` | кому можно писать боту; свой id — команда `/chatid` |
| `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL` | разбор сообщений (OpenAI или OpenRouter) |
| `PUBLIC_URL` | пусто — бот опрашивает Telegram сам (удобно на своём ПК); адрес — webhook |
| `DESKTOP_TOKEN` | ключ для приложения на ПК (или команда `/token` в боте) |
| `DATABASE_URL` | Postgres (на Render — Internal Database URL); пусто — SQLite `data/maid.sqlite` |

Ключи и база в git не идут.

## Учётная запись и перенос из Excel

```
npm --workspace server run user -- create <логин> --password <пароль> [--chat <chat id>]
npm --workspace server run user -- token <логин> --label iphone      ключ для устройства
npm --workspace server run import -- "<файл.xlsx>" [--login <логин>]
```

Если у бота уже есть запись с этим chat id, `create` выдаёт логин ей — данные не теряются.
Импорт можно запускать повторно: уже перенесённое пропускается, в конце — отчёт по количествам.

Шаги с айфона: Быстрая команда «Получить количество шагов за сегодня» → `POST <сервер>/api/steps`,
заголовок `Authorization: Bearer <ключ>`, тело `{"steps": N}`. Повтор за день заменяет число.

## Бот

Обычный текст — запись. Одно сообщение может содержать всё сразу:
«поспал с 2 до 9, на завтрак овсянка, завтра в 15 стоматолог, купить лампочку».
Под ответом — «↩ Отменить» и «📝 Это просто заметка».

`/today` `/plans` `/tasks` `/dates` `/memory` `/habits` — посмотреть, `/ask текст` — просто поговорить,
`/undo` — отменить последнее, `/summary` — итог дня, `/persona` — характер, `/token` — ключ для ПК.

Сама присылает: утром план дня и даты (за 7 дней, за день, в день), вечером — что завтра,
за час до плана со временем, привычки в их время (кнопки «✅ Сделал» / «➖ Пропуск»), вечерний итог,
предупреждение об играх: на 2 ч, дальше каждые 2 ч.

## Приложение для ПК

```
npm run desktop
```

В настройках окна — адрес сервера и ключ. Виджет висит поверх всех окон и не мешает кликать;
**Alt+Shift+M** — взять (двигать, отмечать задачи) и отпустить. **Alt+Shift+Space** — быстрая запись
из любой программы. Время за ПК берётся из [ActivityWatch](https://activitywatch.net) (без AFK), игры —
по списку имён программ в настройках.
