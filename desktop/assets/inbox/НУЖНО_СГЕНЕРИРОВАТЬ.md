# Значки непрочитанных напоминаний

Значки — одиночные эмодзи Google Noto (как в Emoji Kitchen, без смешанных из двух).
Файлы: PNG 512×512 (в игру уменьшаются до 112), прозрачный фон, стиль Noto Emoji.
Готовую картинку положить сюда с тем же именем файла — код менять не нужно.

| Файл | Для чего | Сейчас (временно) | Нужно |
|---|---|---|---|
| `date.png` | важная дата | 🎂 торт (Noto) | — есть |
| `plan.png` | план, «через 15 мин» | ⏰ будильник (Noto) | — есть |
| `mail.png` | остальные напоминания | 💌 письмо с сердцем (Noto) | — есть |
| `pill.png` | таблетка / привычка | 🩺 стетоскоп | 💊 таблетка-капсула в стиле Noto |
| `many.png` | «+N» — ещё напоминания | 🔔 колокольчик | стопка из 2–3 конвертов или почтовый ящик 📬 в стиле Noto |
