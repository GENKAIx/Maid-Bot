# Значки оповещений

Четыре раздела оповещений у горничной (`desktop/renderer/inbox.js`, `IB_GROUPS`). Значки — одиночные эмодзи Google Noto,
PNG 128×128, прозрачный фон; исходники 512×512 — «А ПРИКОЛЫ/Эмодзи». Заменить картинку — положить сюда файл с тем же именем.

| Файл | Раздел | Что в нём |
|---|---|---|
| `alarm.png` | ⏰ Напоминания | планы, вопросы про привычки, просроченные задачи |
| `warn.png` | ⚠ Важное | замечание про игры, наблюдения, сбои разбора |
| `date.png` | 🎂 Важные даты | дни рождения, годовщины, праздники |
| `mail.png` | 💌 Письма | утро, «что завтра», итог дня |
