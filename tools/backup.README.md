# Резерв «Горничная бот»

Копия всего проекта на случай, если пропадёт папка, git или история чата. Обновляется после каждой задачи:
`python tools/backup.py` (докопирует только изменившееся; из резерва ничего не удаляется — удалённые в проекте файлы здесь остаются).

- `проект/` — рабочая папка как есть: код, документы, незакоммиченные правки, локальная база `data/`, записи и рендеры видео.
  Нет: `node_modules`, сборок (`dist`, `build`), `.env` и `secrets/` — ключи в резерв не кладутся, их хранить отдельно.
- `git/maid-bot.bundle` — вся история git (все ветки) одним файлом.
- `чат/` — разговоры с Claude Code по проекту (`*.jsonl`, рядом — их папки с вложениями) и память Claude (`memory/`).
- `СОСТОЯНИЕ.md` — когда сделан резерв, последние коммиты, что было не закоммичено.

## Как восстановить

1. Код с историей: `git clone РЕЗЕРВ/git/maid-bot.bundle "Горничная бот"`, затем `git remote set-url origin https://github.com/GENKAIx/Maid-Bot.git`.
2. Незакоммиченное и файлы вне git — скопировать поверх из `проект/`.
3. Зависимости: `npm install` в корне, `desktop`, `web`, `video`.
4. `.env` и `secrets/` — вернуть из своего хранилища ключей.
5. История чата: файлы из `чат/<папка>/` положить в `%USERPROFILE%\.claude\projects\<папка>\` — разговор снова откроется в Claude Code
   (`claude --resume`), память — в `memory\`.
