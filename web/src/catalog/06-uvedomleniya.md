## Одна функция отправки

Всё, что горничная пишет первой, идёт через `Send`:

```flow
Telegram | сообщение в чат с ботом, кнопки — inline
Push | во все подписки браузеров (`server/src/push.ts`), кнопки — действия push
Уведомления | строка в `notices` — её читают виджет на ПК и сайт
```

Кнопки push (`/api/push/act`) делают то же, что кнопки в Telegram: отметить привычку, отложить напоминание.

## Команды бота

| Команда | Что делает |
|---|---|
| `/start` | знакомство |
| `/today` | что сегодня |
| `/plans` | планы |
| `/tasks` | задачи |
| `/dates` | важные даты |
| `/memory` | что она помнит |
| `/habits` | привычки |
| `/summary` | итог дня сейчас |
| `/list` | виджет-список прямо в Telegram |
| `/undo` | отменить последнее |
| `/ask` | вопрос или разговор без записи |
| `/persona` | сменить характер |
| `/token` | новый ключ для ПК и айфона |
| `/chatid` | служебное |
| `/invite` | только владелец (chat id из `ALLOWED_CHAT_IDS`): одноразовая ссылка-приглашение `t.me/<бот>?start=<код>` на 7 дней. Друг по ссылке получает учётную запись — логин (из @username, занят — с числом; без ника — `friend`) и случайный пароль, адрес сервера и ссылку на установщик программы для ПК (из `latest.yml`; сам файл ботом не шлётся — больше 50 МБ); владельцу — «Новый друг по приглашению». Дальше бот пускает его как своего (`invite.ts`: `isMember` — владелец или чат с учётной записью); чужим без приглашения по-прежнему отвечает только `/chatid` |

Обычный текст, голосовые и фото (подпись к фото — подсказка, картинка файлом тоже подходит) — разбор сообщений.

## Виджет в Telegram

`server/src/widget.ts`: одно сообщение, которое бот правит на месте вместо новых. Состояние зашито в кнопки (не больше 1024 байт), запросы короткие: `d:t12` — отметить задачу 12, `u:t12` — снять отметку, `s` — обновить. Фразы вроде «покажи список» (`asksForList`) открывают его без команды.

## Игры

Трекер ПК раз в 10 минут присылает, что запущено (ActivityWatch). Набралось за день `game_first_min` (120 мин) игры — горничная делает замечание голосом характера (`stern`), дальше — каждые `game_every_min` (120 мин). На каждый порог — одно сообщение. Выключается в настройках (`game_alerts`).

> **Пробел для развития.** Push-подписок может быть несколько (телефон, ПК, ноутбук), и каждое уведомление приходит на все — «прочитано» на одном не гасит другие.
