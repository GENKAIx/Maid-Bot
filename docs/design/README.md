# Дизайн полной версии и виджета

Здесь лежат версии живого макета нового дизайна. Каждая версия — отдельный файл `дизайн-vN-<дата>.html`, старые не правятся.
Открывать двойным щелчком: картинки Рины берутся из `web/public/maid`.

- `дизайн-v1-2026-11-27.html` — исходный дизайн из большого ревью.
- `дизайн-v2-2026-11-27.html` — привычки «Во сколько отмечали» как в программе, календарь дневника с эмодзи и оценкой, тарифы без картинок (аудиоразбор в минутах).
- `дизайн-v3-2026-11-27.html` — как v2, плюс четыре варианта бафов и дебафов в профиле (после «О вас»): «Как в игре», «Состояния на шкале», «Рина заметила», «Персонаж»; в каждом можно попробовать, как эффект появляется, срабатывает в разговоре, убирается и возвращается. (Прежняя отвергнутая v3 с новой системой дизайна откатена 27.11.2026 и в папке не лежит.)
- `дизайн-v4-2026-11-27.html` — как v3, плюс «Привычки: месяц сеткой» отдельным макетом: два цвета (сделано и пропуск), пометка ×N у привычек «несколько раз в день» с частичным заполнением клетки, раскрытие привычки с графиком «Во сколько отмечали» (интервал кнопками и рамкой на полосе), путь к рекорду, сутки циферблатом, дни недели, год и наблюдение Рины.
- `дизайн-v5-2026-11-27.html` — как v4, «Привычки: месяц сеткой» доведены: в клетках три состояния (сделано, пропуск, отмечено не всё), цветные огоньки серий, без совета Рины под таблицей, год в раскрытой привычке разделён по месяцам, текст выровнен.

Опубликованная страница (всегда последняя версия): https://claude.ai/artifact/2UZY7oZNjn97FnmQMdSWh4

## Исходники
`исходники/` — из чего собирается страница: `parts/*.html` (по экрану на файл), общие `shared.css`, `shared.js`, `page.css`,
правила фрагмента `SPEC.md`, проверка `python check.py parts/<экран>.html`.
Сборка новой версии: положить рядом папку `maid/` (копия `web/public/maid`), написать `changes-vN.html` (пункты `<li>`) и
запустить `python build_design.py N "дата"` → `design-vN.html`; для папки проекта пути `maid/` заменяются на `../../web/public/maid/`.
