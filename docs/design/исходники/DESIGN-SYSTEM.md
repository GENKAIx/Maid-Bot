# Дизайн-система «Горничной» (версия 3)

Цель: спокойный интерфейс, в котором глаз сразу находит одно главное. Цвет — редкий сигнал, а не украшение.
Все правила ниже обязательны для каждого экрана внутри `.app`. Готовые классы — в `shared.css` (раздел «Дизайн-система»).

## 1. Три слоя внимания
На каждом экране и в каждой карточке есть ровно три уровня:
1. **Главное** (одно на экран): крупное число или заголовок, одна заливная кнопка `.btn.primary`.
2. **Рабочее**: списки, строки, графики. Текст `--a-text`, без цвета.
3. **Фон**: подписи, подсказки, даты, единицы — `--a-muted`, мелко.
Если на экране два «главных» — одно из них понижается.

## 2. Цвет
- **Поверхности нейтральные.** Фон `--a-bg`, карточки `--a-surface`, вложенное `--a-surface-2`. Никаких цветных заливок карточек.
  Единственное исключение — выбранный/текущий элемент: `--a-accent-soft` + рамка `--a-accent`.
- **Акцент (фиолетовый) — только для действия и выбора:** заливная кнопка, выбранная вкладка/фильтр, фокус, ссылка, линия «сейчас».
  Не для заголовков, не для украшений, не для цифр (кроме одного выделенного слова в реплике Рины).
- **Цвет данных** (`--c-sleep`, `--c-pc`, `--c-game`, `--c-habit`, `--c-money`, `--c-mood`) — только внутри графиков, колец, полос
  и как точка `.dot` 8 px рядом с названием. Текст и фон кнопок цветом данных не красим.
- **Статус** (`--a-ok`, `--a-warn`, `--a-bad`) — только для состояния и всегда со словом или значком: «Просрочено», «✓ в норме».
  Красный — только ошибка/просрочка/удаление. Оранжевый — «внимание». Зелёный — «готово/в норме». Не больше одного статуса на строку.
- **Золото `--a-gold`** — только очки ✦ и награды. Не для кнопок и карточек.
- **Категории** (работа, дом, покупки…) — нейтральная метка `.tag` с точкой цвета, без цветного фона и рамки.
- Предел: в одной карточке не больше **двух** цветов кроме нейтральных (например, цвет данных графика + акцент выбора).

## 3. Шрифт
Внутри `.app` только **Onest** (`--f`). Unbounded в программе не используется.
| Роль | Класс | Размер / вес |
|---|---|---|
| Заголовок экрана (в шапке рамки) | — | 18 / 700 |
| Заголовок блока | `.h` | 15 / 650 |
| Метка над блоком | `.label` | 12 / 600, приглушённый, без капса |
| Основной текст | — | 14 / 400 |
| Вторичный | `.muted` / `.small` | 13 / 400 |
| Число в карточке | `.num-l` | 24 / 650 |
| Главное число экрана (одно) | `.num-xl` | 36 / 700 |
Капслок (UPPERCASE) не используем. Жирный — только для чисел и названий.

## 4. Сетка и отступы
Шаг 4: 4, 8, 12, 16, 24, 32. Отступ внутри карточки 16 (на телефоне 12), между карточками 16, между секциями 24.
Скругления: 8 (кнопки, поля, метки), 12 (строки, вложенные блоки), 16 (карточки). Тени внутри программы не используем — только линия `--a-line`.
Карточка = фон `--a-surface` + линия **или** просто фон; не рамка + тень + градиент одновременно.

## 5. Детали (компоненты)
- **Кнопки.** `.btn.primary` — одна на блок (лучше одна на экран). `.btn` — обычная (нейтральная, с линией). `.btn.quiet` — без рамки, для второстепенного. `.icon-btn` — 32×32 значок с `aria-label`.
- **Действия у строки списка** (перенести, в план, удалить) не показываются на каждой строке постоянно: они в `.row-acts`,
  который появляется при наведении/фокусе строки, а на телефоне — по нажатию на строку (раскрытие). Видна только галочка/главный клик.
- **Метка** `.tag` — серый фон, 12 px, без рамки; не больше двух меток в строке, остальное в раскрытии.
- **Фильтры** — `.seg` или ряд `.chip`; выбранный — акцент, остальные нейтральные. Счётчики в фильтрах — приглушённые.
- **Пустое состояние** `.empty` — одна фраза и одно действие.
- **Отмена** — одна плашка `.undo` внизу рамки: «Задача удалена · Отменить». Без окон «Вы уверены?».
- **Подсказки-инструкции** («Перетащите…», «Нажмите…») — не больше одной на экран, приглушённым мелким текстом, или убрать.
- **Рина** `.rina` — одна на экран, картинка 48 px в круге, короткая фраза (до 2 строк) и не больше одной кнопки-действия.
  Если картинка не загрузилась, вместо неё круг с буквой «Р» (делает `shared.js`).
- **Числа-плитки** (сон, шаги…) — максимум 4 в ряд; в плитке одно число, одна подпись, одна тонкая полоса прогресса цветом данных.

## 6. Плотность
- Не больше **7 строк** в списке до «Показать ещё».
- Не больше **3 действий**, видимых одновременно в блоке.
- Каждый элемент должен отвечать на вопрос «что мне сделать / что важно сейчас». Декоративные счётчики, повторяющиеся подписи, дублирующие кнопки — убрать.
- Повторяющиеся подписи у каждой строки («~15 мин», «Срок: …») — только если различаются и важны.

## 7. Движение
200–400 мс, `var(--ease)`. Анимируем смысл: появление, перелёт, рост числа. Ничего не мигает и не качается постоянно.

## 8. Темы
Тёмная и светлая — одни и те же токены (`body[data-skin="light"]`). Литеральных цветов в макетах нет.
