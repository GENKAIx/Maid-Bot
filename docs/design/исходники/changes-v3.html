• Дизайн-система: новая витрина в начале страницы. В ней цвета для обеих тем, шрифт, отступы, общие детали и правила «можно / нельзя».
  • Цвет: поверхности нейтральные. Фиолетовый только для действия и выбора. Цвета данных только в графиках и точках, статусы только со словом, золото только для ✦.
  • Меньше шума: одна заливная кнопка на блок. Действия у строк появляются при наведении или по нажатию. Метки серые, капслока нет, везде один шрифт Onest.
  • Рина: на каждом экране одна, картинка в круге 48 px. Если картинка не загрузилась, вместо неё круг с буквой.
