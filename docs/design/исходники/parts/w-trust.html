    Что изменилось

    • Одна страница отвечает на вопрос «что обо мне хранится»: шесть видов записей, у каждого число и простое описание.
    • Сбор времени за ПК выключается прямо здесь. Рина сразу говорит, что будет со старыми записями.
    • Скачивание в трёх видах: полная копия, таблицы для Excel, календарь.
    • Аккаунт человек удаляет сам. Видно, что сотрётся, нужно написать слово, и есть 7 дней, чтобы передумать. Системных окон нет.
    • Блокнот Рины переехал из команды бота на экран: 12 фактов по группам, каждый можно поправить или стереть.

    Анимации

    • Числа досчитываются с нуля, плитки и строки блокнота появляются по очереди.
    • Кнопка скачивания заполняется полоской, пока файл собирается, потом показывает галочку и имя файла.
    • Буквы слова УДАЛИТЬ загораются по мере ввода. Кнопка включается только на полном слове.
    • Счётчик дней до удаления: полоски гаснут по одной, число слегка подпрыгивает.
    • Стирание факта: короткая вспышка от кнопки по всей строке, текст расплывается. На его месте строка «Стёрто» с кнопкой «Отменить» и убывающей полоской на 6 секунд.

    Что нужно в коде

    • Числа по видам: записи уже лежат в базе, нужен один запрос-сводка.
    • Выключатель сбора сейчас только в программе на ПК. Вынести на сайт и спрашивать согласие при первом запуске.
    • Копия в JSON уже скачивается. Таблицы CSV и календарь .ics надо дописать, работа небольшая.
    • Удаление на сервере готово, но вызывается только из админки. Дописать: просьбу с датой, отмену, напоминание за день, выход со всех устройств. Решить, как записи уходят из ночных копий базы.
    • Текста правил и отметки о согласии в коде нет. Нужен текст от юриста и дата согласия у каждого человека.
    • Блокнот: список фактов есть (команда /memory в боте). Дописать правку и стирание одного факта, а ещё дату и источник, если их нет в записи.
