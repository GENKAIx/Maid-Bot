✓ Можно

  • Одна заливная кнопка на блок, остальные обычные или тихие.
  • Акцент для действия и выбора: вкладка, фокус, ссылка.
  • Цвет данных в графиках, кольцах, полосах и точках.
  • Статус со словом: «Просрочено», «✓ в норме».

✕ Нельзя

  • Цветные заливки, цветные рамки и градиенты у карточек.
  • Кнопки действий на каждой строке постоянно.
  • Капслок, второй шрифт, больше двух меток в строке.
  • Золото где-то, кроме очков ✦ и наград.

Стало · версия 3

Одна серая метка, срок приглушён. Просрочку показывает заголовок группы, действия появляются при наведении.

Что изменилось

  • Новая витрина: цвета обеих тем, шрифт, отступы и общие детали в одном месте. По ней сверяются все экраны ниже.
  • Из второй версии убраны цветные карточки, градиенты, капслок, шрифт Unbounded, кнопки на каждой строке и цветные метки.
  • Цвет стал сигналом: акцент только для действия и выбора, цвета данных только в графиках, статус всегда со словом, золото только у ✦.

Анимации

  • Плашки цветов и строки шрифта появляются по очереди, линейка отступов вырастает, полосы в плитках заполняются, числа досчитывают.
  • Галочка зачёркивает строку, снизу всплывает плашка «Отменить». Удалённая строка схлопывается.
  • В «Трёх слоях» выбранный слой остаётся ярким, остальное плавно гаснет.

Что нужно в коде

  • Один файл токенов для обеих тем: цвета, отступы, скругления. Экраны берут цвета только из него.
  • Общие детали в одном месте: кнопка, метка, статус, строка с действиями, плашка отмены, блок Рины. Свои копии на экранах убрать.
  • Отмена вместо окон «Вы уверены?»: удаление откладывается на 5 секунд, пока видна плашка.
  • Шрифт Onest вшить в программу, Unbounded из программы убрать.
