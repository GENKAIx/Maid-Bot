      Что изменилось

      • Главное дело без золотой заливки: обычная карточка с фиолетовой чертой слева. На экране одна заливная кнопка, «В план на 15:00».
      • У задач больше нет постоянных кнопок. «В план» и «На завтра» появляются при наведении, на телефоне по нажатию на строку. Ручка для перетаскивания тоже.
      • Плитки сон, шаги, вода, оценка спокойные: подпись, одно число, одна тонкая полоса цветом данных. Без капса и цветных рамок.
      • Уровень ✦ сжат в одну строку в шапке. Убраны счётчики «Задачи · 4», зелёный заголовок «Сделано», огоньки у серий, «Прошло планов» в варианте Б.
      • Рина одна: её фраза и строка «Скажите Рине…» стоят вместе, ответ приходит в тот же пузырь. Подсказки-фразы видны, только когда строка в фокусе.
      • Шкала нейтральная: блоки серые, цветом выделены только текущее дело и линия «сейчас» (фиолетовая). Один шрифт Onest.

      Анимации

      • Вход: линия «сейчас» доезжает до 13:40, прошлое мягко затеняется, блоки появляются по очереди.
      • Отмеченная задача перелетает в «Сделано», всплывает +10 ✦, полоса уровня дорастает.
      • Привычка: кольцо пульсирует, серия прибавляет единицу.
      • При перетаскивании окно подсвечивается и показывает время, куда встанет задача.
      • Сохранённый факт коротко вспыхивает цветом своей полосы.

      Что нужно в коде

      • Есть: /api/today отдаёт планы с концом, задачи, привычки с серией, метрики. Шкала строится без нового сервера.
      • Есть на сервере, сайт не зовёт: /api/tasks/:id/plan, правка даты задачи, POST /api/rate для оценки.
      • Дописать: длительность задачи (пока 30 мин по умолчанию), признак «главное дело» (одно в день), ввод сна и шагов с сайта, новая метрика «вода».
      • Новое: очки ✦ и уровни. Это отдельный счёт, со звёздами Telegram он не связан.
