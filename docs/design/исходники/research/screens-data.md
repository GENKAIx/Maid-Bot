## 2. Вкладка «Сон» — особое внимание
**Данные.** Отдельной таблицы сна НЕТ. Сон = (а) записи дневника `section="sleep"` (свободный текст) + (б) показатель `sleep_hours`. Время отбоя/подъёма вычисляется НА КЛИЕНТЕ регулярками из текста (`parseSleep`, web/src/sleep.tsx): «лёг в…», «встал в…», «с 2 до 9», «спал 7 ч». Итог на день: `{day, bed?, wake?, hours?}` — один интервал на день (первая запись побеждает, `??=`); дневной сон/второй интервал не поддержан. Качества сна, фаз, пробуждений, цели сна нет. Есть заметка к сну (до 300 символов, дописывается в текст записи). Желаемые подъём и отбой хранятся в «О вас» (`wake`, `bed`, server/src/you.ts), но во вкладке «Сон» не используются. Оценка дня `rating_day` 1–10 — для графика «Сон и оценка дня» (web/src/sleepscore.ts).
**Действия.**
- Щелчок по строке дня → форма под строкой: «Лёг», «Встал» (input type=time), заметка, «Сохранить», «Удалить сон» (через браузерный `confirm`), «Отмена» → `POST /api/sleep` (api.ts:986): старые записи сна дня уходят в удалённые, создаётся одна «лёг в…, встал в…».
- Перетаскивание полосы на другой день (мышь — сдвиг ≥6 px, палец — удержание 300 мс): перенос или обмен → `POST /api/sleep/swap` (api.ts:1005), плашка «↩ Отменить» (`POST /api/undo`), Esc — отмена.
- В графике «Сон и оценка дня» — наведение/касание точки, раскрывающееся «Таблицей».
**Сейчас.** Карточка «Сон»: шкала 18:00 накануне → 18:00, строка на день (дата · дорожка 18 px с синей полосой и подсветкой 22:00–7:00 · часы), в шапке «в среднем N ч · отбой ~, подъём ~». Вторая карточка (не в виде «День») — точечный график часы сна × оценка и одна строка-вывод («После 8 ч и больше — в среднем 7,2…»).
**UX-проблемы.**
- Правка и перетаскивание скрыты: подсказка только в `title` и в мелкой серой легенде внизу; нет кнопки «+ записать сон», нет ручек у полосы — нельзя потянуть край, чтобы изменить время (тянется только весь сон между днями).
- Строки очень низкие (дорожка 18 px, зазор 3 px, styles.css:786–795) — на телефоне мелкая цель для касания и долгого нажатия; на ≤760 px подписи времени на полосе и промежуточные деления скрыты (styles.css:837–841).
- Перенос с клавиатуры невозможен (Enter только открывает форму).
- В «3 месяца» и «Год» шкала показывает лишь последние 31 день со сном (`slice(-31)`), и «в среднем» в шапке считается по этим же строкам, а не по всему периоду (Stats.tsx, `sleepRows`/`slept`); агрегата по неделям/месяцам для сна нет.
- В квартале/годе пустых дней нет — добавить сон на пропущенный день можно только из дня/недели/месяца.
- Нет цели сна, регулярности, «долга сна», сравнения с желаемым отбоем/подъёмом; нет качества.
- Сон, не попадающий в окно 18:00–18:00, обрезается (`Math.min(24, …)` в `span`).
- Данные хрупкие: время берётся разбором русского текста на клиенте; запись без распознанного времени рисуется как «N ч — время не записано».
