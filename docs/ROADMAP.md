# Горничная — дорожная карта

Составлена 08.11.2026 по ответам пользователя. Устройство и прежние решения — `АРХИТЕКТУРА.md`.

## Что хотим получить

Личный ассистент. Пишешь как есть — с телефона или ПК — горничная раскладывает сама:
задачи, планы, важные даты, дневник дня (заметки, сон, спорт, еда, здоровье, хобби), привычки, деньги.
Напоминает вовремя, считает время за ПК и в играх, отвечает на вопросы по записям,
показывает результаты и динамику графиками. На ПК — милая аниме-горничная поверх окон.

### Этап 2. Веб-приложение — в работе
- PWA: устанавливается на iPhone и ПК, работает одной ссылкой.
- Экраны: «Сегодня» (планы, задачи, привычки, кольца дня), календарь недели, задачи (закрывать),
  планы, даты и дни рождения, дневник по дням, сон (удобный вывод: график часов и времени отбоя/подъёма),
  привычки (сетка месяца), здоровье, деньги, статистика (ПК, игры, шаги, сон — по дням, неделям, месяцам).
- Строка ввода на каждом экране — пишешь как в чат.
- Анимации переходов, появления карточек, отметки привычек.
- Приложение для ПК открывает то же веб-приложение; виджет и быстрая запись остаются.

Готово, когда: всё из этапа 1 видно и правится в приложении на ПК.

Сделано (08.11.2026, первая пачка — ежедневные экраны): пакет `web` (React + Vite + TS, без UI-библиотек), сервер
отдаёт `web/dist` с корня и на любой адрес экрана (`/diary/2026-11-08`) — `index.html`; вход по логину и паролю
(`/api/login`, ключ в localStorage); «Сегодня» — кольца дня (привычки, сон/8 ч, шаги/10 000, спорт/30 мин, ПК, игры),
планы и ближайшие, задачи (закрыть галочкой), привычки (✓ / –, серии 🔥), даты, дневник по разделам, показатели и деньги;
«Дневник» — календарь месяца с точками по дням с записями (`/api/diary/days`), день (`/api/day`) по разделам с подразделами
здоровья, удаление записи (`DELETE /api/diary/:id`), показатели, деньги, компьютер, планы и привычки дня; «Привычки» —
кольца месяца и сетка (строка — привычка, столбец — день; щелчок — сделал / пропуск). Строка ввода на каждом экране, ответ
с «Отменить». Манифест PWA и значки. Десктоп: главное окно открывает это же приложение с сервера; настройки — из трея.
Вторая пачка (08.11.2026): «Планы» — неделя днями (стрелки по неделям), что дальше на 2 месяца, все задачи, все
важные даты с ближайшим наступлением (`/api/dates?all=1`); «Здоровье» — подразделы с числом записей («Без подраздела» —
перенос из Excel), поиск по словам (`/api/diary?section=health&q=`), записи по дням со ссылкой на день; «Деньги» —
месяц / год / всё, доходы, расходы и итог по валюте, расходы по дням столбиками, доли по категориям, список;
«Статистика» — неделя / месяц / 3 месяца (по неделям) / год (по месяцам): ПК, игры (цель 2 ч), сон (8 ч), шаги (10 000),
спорт (30 мин), вес, другие показатели, записи о сне, самые частые программы и игры (`/api/activity?from&to`).
Графики — свои столбики без библиотек (`web/src/charts.tsx`), подсказка при наведении. На телефоне в меню снизу
четыре экрана и «Ещё» (здоровье, деньги, статистика, выход). Проверка живости сервера — `/healthz` (`/health` занят экраном).

### Этап 3. Сервер в облаке и уведомления — сделано (08.11.2026)
- Выкладка на Render (Starter + Postgres), резервные копии базы.

Готово, когда: уведомление с айфона отмечает привычку, и отметка видна на ПК.

Сделано: `render.yaml` (Web Service Starter + Postgres Basic, `/healthz`, сборка приложения при деплое), пошагово —
`docs/RENDER.md`. Web Push (`server/src/push.ts`, пакет `web-push`, ключи VAPID — `npm --workspace server run vapid`):
подписка браузера (`push_subs`, `/api/push/key|subscribe|unsubscribe|test`), service worker `web/public/sw.js`
показывает уведомление с кнопками; кнопка без открытого приложения — подписанный HMAC список (`/api/push/act`, 36 ч):
«✅ Сделал» / «➖ Пропуск» отмечают привычку, «⏰ Через 30 мин» ставит напоминание с теми же кнопками (`reminders.buttons`).
Планировщик работает всегда (раньше — только с ботом): уведомление уходит в Telegram и на все push-подписки.
Экран «Настройки»: включить/выключить на этом устройстве, проверить, время утреннего списка / «что завтра» / итога,
за сколько напоминать о плане, предупреждения об играх (`POST /api/settings`), «Скачать копию» (`GET /api/backup`), выход.
Резервная копия (`server/src/backup.ts`): JSON всех записей, раз в сутки в 03:30 в Telegram файлом (если бот есть),
`npm --workspace server run backup` — в `data/backups`. Тесты: 24 (push — подпись, кнопка без входа, «отложить», настройки, копия).
Живьём на Render и на iPhone не проверено — по `docs/RENDER.md`. Восстановление из JSON-копии — на потом.

### Отложено (решение пользователя 08.11.2026)
- **Веб-приложение на телефоне и домен.** Сервер стоит на VPS Hostinger (KVM 1, Германия, IP 187.126.11.122) **без домена**:
  Telegram-бот и приложение на ПК работают по IP. Без HTTPS браузер не даёт push, service worker и установку на экран «Домой»,
  поэтому веб-приложение на iPhone и push-уведомления отложены. Когда понадобятся: взять домен (бесплатный год `.tech`/`.cloud`
  в тарифе Hostinger — `genkaix.cloud` был свободен; или DuckDNS бесплатно, или `.xyz` ~2 $), записать A-запись на IP, в `/srv/.env`
  на сервере поставить `MAID_DOMAIN=maid.<домен>` и перезапустить `docker compose up -d` — Caddy выпустит сертификат сам.
- Трафик ПК ↔ сервер пока без шифрования; план — WireGuard на том же VPS, ПК через него.
