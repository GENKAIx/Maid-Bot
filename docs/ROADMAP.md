# Горничная — дорожная карта

Составлена 08.11.2026 по ответам пользователя. Устройство и прежние решения — `АРХИТЕКТУРА.md`.

## Что хотим получить

Личный ассистент. Пишешь как есть — с телефона или ПК — горничная раскладывает сама:
задачи, планы, важные даты, дневник дня (заметки, сон, спорт, еда, здоровье, хобби), привычки, деньги.
Напоминает вовремя, считает время за ПК и в играх, отвечает на вопросы по записям,
показывает результаты и динамику графиками. На ПК — милая аниме-горничная поверх окон.

## Решения пользователя (08.11.2026)

| Вопрос | Решение |
|---|---|
| Кто пользуется | пока только я, но заложить учётные записи для продажи потом |
| Главный интерфейс | **веб-приложение (PWA)**: на iPhone — с экрана «Домой», с уведомлениями; на ПК — то же в окне приложения |
| Telegram | не обязателен; оставить выключаемым запасным вводом |
| Google Таблица | **убрать** |
| Сервер | Render: Web Service Starter + Postgres Basic (~13 $/мес; цены сверить на сайте) |
| Нейросеть | OpenRouter, хорошая модель (~10–20 $/мес), модель меняется в настройках |
| Часовой пояс | UTC+3 |
| Вид | светлый, карточки, кольца прогресса, серии дней — как в HOLO (скрин пользователя) |
| Оценка «продуктивности» | не нужна; нужны результаты и динамика |
| Привычки | отметки на месяц вперёд; общий список утром + напоминание в своё время; отмечать кнопкой в уведомлении и в приложении; серии дней |
| Здоровье | записи по разделу «Здоровье» с подразделами (давление, сердце, таблетки…), быстрый поиск по вопросу |
| Деньги | новый раздел: «получил / потратил» свободным текстом → упорядоченные доходы и расходы |
| Игры | предупреждения не каждый час (по умолчанию: на 2 ч и дальше каждые 2 ч, настраивается) |
| Айфон | только шаги (Команды) |
| Горничная-персонаж | аниме-девушка, только на ПК; пока — заглушка |
| Obsidian | выгрузка не нужна |
| Старые данные | перенести всё из Excel (`2026 заметки v2.xlsx`) |

Время по умолчанию (поменять в настройках): утренний план 09:00, вечерний итог 22:00.

## Этапы

### Этап 0. Основа — сделано (08.11.2026)
Сервер (свободный разбор одним вызовом, уточняющий вопрос, отмена), напоминания, бот Telegram,
приложение для ПК: виджет поверх окон, быстрая запись, трекер ActivityWatch. 12 тестов.

### Этап 1. Данные
- Слой хранения, работающий и с SQLite (у себя), и с Postgres (Render).
- Новые разделы: привычки (расписание, отметки по дням, серии), деньги (доходы/расходы, категории, валюта),
  здоровье с подразделами, шаги.
- Учётная запись пользователя с паролем (вход в веб-приложение) — сразу с расчётом на нескольких.
- Убрать зеркало Google Таблицы.
- **Перенос из Excel**: листы «2026» (дневник по дням, ~270 заполненных), «Планы», «Задачи», «Даты», «Доходы»;
  итог переноса — отчёт «сколько чего перенесено, что не разобрано».

Готово, когда: старые записи видны в базе, тесты на перенос и новые разделы зелёные.

### Этап 2. Веб-приложение
- PWA: устанавливается на iPhone и ПК, работает одной ссылкой.
- Экраны: «Сегодня» (планы, задачи, привычки, кольца дня), календарь недели, задачи (закрывать),
  планы, даты и дни рождения, дневник по дням, сон (удобный вывод: график часов и времени отбоя/подъёма),
  привычки (сетка месяца), здоровье, деньги, статистика (ПК, игры, шаги, сон — по дням, неделям, месяцам).
- Строка ввода на каждом экране — пишешь как в чат.
- Анимации переходов, появления карточек, отметки привычек.
- Приложение для ПК открывает то же веб-приложение; виджет и быстрая запись остаются.

Готово, когда: всё из этапа 1 видно и правится в приложении на ПК.

### Этап 3. Сервер в облаке и уведомления
- Выкладка на Render (Starter + Postgres), резервные копии базы.
- Push-уведомления (Web Push) на iPhone и ПК: кнопки «✅ Сделал» / «Отложить».
- Утренний список (планы, привычки, даты), напоминания привычек в своё время, планы за день/в день/за час,
  дни рождения за 7 дней/за день/в день, вечерний итог, предупреждения об играх.
- Трекер ПК и шаги с айфона шлют данные на облачный сервер.

Готово, когда: уведомление с айфона отмечает привычку, и отметка видна на ПК.

### Этап 4. Умная горничная
- Вопросы по своим записям: «когда болело сердце?», «сколько потратил на еду в октябре?» —
  поиск по базе, ответ со ссылками на дни.
- Автоматическое упорядочивание: здоровье — по подразделам, деньги — по категориям; новый подраздел
  появляется сам, когда тема встречается повторно (без лишних вопросов).
- Итоги недели и месяца с динамикой: сон, игры, ПК, шаги, спорт, привычки, деньги.

### Этап 5. Аниме-горничная на ПК
- Персонаж в углу экрана: появляется с уведомлением, облачко с текстом, несколько состояний
  (рада, ворчит из-за игр, напоминает, спит ночью).
- Сначала заглушка (простая нарисованная), потом картинки и анимации пользователя.

### Потом
- Продажа: регистрация, оплата, отдельные данные каждого.
- Telegram как запасной ввод (включается в настройках).
- Больше данных с айфона, если понадобится.

## Порядок и проверка
Этапы по порядку; каждый — своими коммитами и тестами без сети. После этапа — короткий список того,
что проверить руками (уведомления на телефоне, вид на экране).
